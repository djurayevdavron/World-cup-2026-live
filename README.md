# FIFA World Cup 2026 Live

FIFA World Cup 2026 Live is a football tournament tracking platform built with React, Vite, and Tailwind CSS. | FIFA World Cup 2026 Live — React, Vite va Tailwind CSS yordamida yaratilgan futbol turnirini kuzatish platformasi.

## Features

* Multi-language support (English, Uzbek, Russian) | Ko'p tilli tizim (English, Uzbek, Russian)
* FIFA World Cup 2026 Countdown | FIFA World Cup 2026 Countdown
* Group Stage Standings | Guruh bosqichi jadvali
* Automatic Standings Calculation | Avtomatik turnir jadvali hisoblash
* Best Third-Placed Teams Ranking | Eng yaxshi uchinchi o'rin jamoalari reytingi
* Upcoming Matches | Kelgusi o'yinlar
* Next Match Section | Keyingi o'yin bo'limi
* Last Finished Match Section | Oxirgi yakunlangan o'yin bo'limi
* Live Match Page | Jonli o'yin sahifasi

* Fully Responsive Design | To'liq moslashuvchan dizayn
